# No Antenna website source

This repository contains the source code and visual assets exported from the No Antenna Site at source commit `bb2aea5df4568b2c1566d6bcde44803fd0395255`.

The app uses a Cloudflare Worker runtime and a D1 database for discussion requests. The `.openai/hosting.json` file belongs to the ChatGPT Sites deployment. To host elsewhere, configure the build and a separate database binding. Runtime credentials and database records are not included.
